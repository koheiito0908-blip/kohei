# 平和島予想 (Kyotei Heiwajima Predictor)

ボートレース**平和島**(jcd=04)専用の、統計ベースの競艇予想ツールです。
BOAT RACEオフィシャルサイトから実際のレースデータを自動収集し、スマホ向けの
静的サイト(GitHub Pages)として予想を表示します。機械学習ではなく、コース別勝率・
選手成績・モーター成績などを重み付け合成したシンプルなスコアリングです。

## 構成

```
scripts/
  lib/heiwajima.py     # 公式サイトの出走表・直前情報・結果ページを取得してマージ
  lib/http.py          # 丁寧なHTTP取得(間隔・リトライ)
  collect_data.py       # 指定期間のレースデータを収集し docs/data/races/*.json に保存
  build_stats.py        # コース別(進入コース別)成績を集計 docs/data/stats/course_stats.json
  predict_today.py      # 当日の出走表を取得しスコアリング docs/data/predictions/*.json
docs/                    # GitHub Pagesとして配信する静的サイト本体
  index.html / app.js / style.css
  data/                  # 収集・生成されたJSON(サイトが直接fetchする)
.github/workflows/update-data.yml   # 定期収集・予想生成・自動コミットのワークフロー
```

## データ収集について(重要)

このツールはBOAT RACE公式サイト (https://www.boatrace.jp/) の出走表・直前情報・
結果ページをスクレイピングして統計を作ります。このリポジトリを作業した開発環境は
ネットワークポリシーにより公式サイトへ直接アクセスできなかったため、**実データの収集は
GitHub Actions(通常のインターネットアクセスを持つ)側で行う設計**にしています。

### 1. 初回セットアップ: 過去1年分のバックフィル

GitHub上でこのリポジトリの **Actions → Update Heiwajima data & predictions →
Run workflow** を開き、`start_date` に1年前の日付(例: `2025-07-25`)を入力して実行してください。
公式サイトへの負荷を抑えるため1リクエストごとに約0.4秒の間隔を空けており、
1年分(約4,300レース)の取得には数時間かかることがあります。GitHub Actionsの
ジョブタイムアウトは350分に設定していますが、それでも終わらない場合は
`start_date`/`end_date` を数か月単位に区切って複数回実行してください
(`collect_data.py` は既に取得済みの日付をスキップするので再実行しても安全です)。

### 2. 日次更新

上記ワークフローは毎日 JST 10:00 / 13:00 / 16:00 / 19:00 / 22:00 に自動実行され、
当日のレースを収集・予想を更新し、直前情報(展示タイム等)が出た分だけ精度が上がります。
最後の実行で確定結果を取り込み、`docs/data/stats/course_stats.json` に反映されます。

### ローカルで試す場合

```bash
pip install -r requirements.txt
python scripts/collect_data.py --date 2026-07-20   # 1日分収集
python scripts/build_stats.py                        # コース別統計を再集計
python scripts/predict_today.py --date 2026-07-20    # その日の予想を生成
python -m http.server 8000 --directory docs           # http://localhost:8000
```

## GitHub Pagesの有効化

Settings → Pages → Source を **Deploy from a branch**、Branch を
`claude/kyotei-prediction-tool-tz7dao`(または本ツールをマージした後のブランチ)、
フォルダを **/docs** に設定してください。設定後、ワークフローが `docs/data/` を
更新するたびにサイトへ反映されます。

## 予想ロジック

各レースの6艇について、以下を**レース内で相対的にmin-max正規化**した上で重み付け合成しています
(直前情報がまだ無い時間帯は該当項目を除いた残りの重みで再正規化):

| 指標 | 重み | 出典 |
|---|---|---|
| コース(進入)別勝率 | 0.30 | 自サイト収集の平和島実績(全国平均ではなく場固有の値) |
| 当地勝率 | 0.20 | 公式サイト出走表 |
| 全国勝率 | 0.15 | 公式サイト出走表 |
| モーター2連率 | 0.20 | 公式サイト出走表 |
| ボート2連率 | 0.05 | 公式サイト出走表 |
| 展示タイム | 0.05 | 公式サイト直前情報(公開後のみ) |
| 展示スタートタイミング | 0.05 | 公式サイト直前情報(公開後のみ) |

### 期待値ベースの買い目(value_bets)

まだ走っていないレースでは、上記スコアをPlackett-Luceモデルで3連単の着順確率に変換し、
公式オッズ(公開後のみ取得)と掛け合わせて「確率 × オッズ = 期待値」で上位5点を算出します
(`docs/data/predictions/*.json` の `value_bets`)。予想順位が高いことと期待値が高いことは
必ずしも一致しません(人気すぎる=オッズが低い組み合わせは期待値が下がるため)。控除率が
あるため期待値1超えでも実際の的中を保証するものではありません。
