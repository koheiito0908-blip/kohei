🚤 平和島予想

直近に収集した平和島のレース結果から集計した、コース(進入)別の成績です。全国平均ではなく平和島固有の傾向です。

予想ロジック

機械学習ではなく、以下の指標を重み付けして合成した統計スコアで順位を予想しています。

  • コース別勝率(平和島) — 自サイトで収集した実績値。最大の重み。
  • 当地勝率 / 全国勝率 — 公式サイト掲載の選手成績。
  • モーター2連率 / ボート2連率 — 公式サイト掲載の今節成績。
  • 展示タイム / 展示スタート — 直前情報が公開され次第反映(未公開時は他指標で代替)。

期待値(買い目)について

各艇のスコアを確率に変換し、公式オッズが公開されたレースでは「勝ちそうな確率 × オッズ」で 3連単の期待値を計算し、上位5点を表示します。期待値が1を超えても的中を意味しません (控除率があるため、平均的にはほとんどの買い目が1未満になります)。オッズ未公開のレースは表示されません。

本ツールは公開統計に基づく参考情報であり、的中や利益を保証するものではありません。 舟券の購入は自己責任で、20歳未満は購入できません。データは BOAT RACEオフィシャルウェブサイト から取得しています。
